### 6.2 Typography

**Font Family:** `Onest` (Google Fonts)
**URL:** `https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600;700`

| Weight | Value | Usage |
|--------|-------|-------|
| Regular | 400 | Body text, descriptions |
| Medium | 500 | Nav items, labels, metadata |
| Semibold | 600 | Headings, brand name, key stats |
| Bold | 700 | Watermarks, display text |

| Scale | Size | Usage |
|-------|------|-------|
| H1 Hero | 3rem–3.75rem | Main headline |
| H1 Mobile | 2.25rem | Mobile headline |
| H2 Section | 2.25rem–3rem | Section headings |
| H2 Stat | 1.875rem–2.25rem | Stats headings |
| H3 Card | 1.5rem–1.875rem | Card titles |
| Body | 0.875rem (14px) | Descriptions, paragraphs |
| Label | 0.75rem (12px) | Uppercase labels, metadata |
| Caption | 0.625rem (10px) | Micro text, sub-labels |

**Letter spacing:**
- Headings: `-0.02em`
- Labels/uppercase: `0.025em–0.06em`
- Body: normal

**Line height:**
- Headings: `0.98–1.35`
- Body: `1.5–1.65`
